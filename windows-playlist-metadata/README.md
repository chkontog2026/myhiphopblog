# Greek MP3 Metadata

Windows εφαρμογή για μαζική μετατροπή Greeklish filenames και ID3 metadata σε ελληνικά.

1. Επιλογή φακέλου άλμπουμ.
2. Αυτόματη ανάγνωση τίτλου, καλλιτέχνη, άλμπουμ, track number και ημερομηνίας.
3. Έλεγχος/διόρθωση καλλιτέχνη, τίτλου δίσκου και ημερομηνίας κυκλοφορίας.
4. Προαιρετικός έλεγχος στο Discogs, με βαθμολογία πιθανών κυκλοφοριών και επιλογή της σωστής έκδοσης.
5. Αντιστοίχιση του επίσημου Discogs tracklist με βάση τον αριθμό κομματιού.
6. Δημιουργία νέου ασφαλούς φακέλου στη μορφή `Καλλιτέχνης - Τίτλος άλμπουμ (Χρονολογία)` με διορθωμένα αντίγραφα MP3.

Τα αρχικά αρχεία δεν τροποποιούνται.

## Discogs

Η αναζήτηση χρειάζεται προσωπικό Discogs API token. Το token εισάγεται μέσα στην εφαρμογή και αποθηκεύεται κρυπτογραφημένο για τον τρέχοντα λογαριασμό Windows. Αν δεν υπάρχει σύνδεση ή δεν βρεθεί αξιόπιστη κυκλοφορία, η εφαρμογή συνεχίζει κανονικά με την τοπική μετατροπή Greeklish.

Τα αποτελέσματα εμφανίζονται πριν εφαρμοστούν. Αν η βεβαιότητα είναι χαμηλότερη από 70%, ζητείται πρόσθετη επιβεβαίωση.

Data provided by [Discogs](https://www.discogs.com).
